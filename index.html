💬 1 · Conecta tu Discord

  1. En Discord: Ajustes del servidor → Widget.
  2. Activa Enable Server Widget y elige un canal de invitación.
  3. Copia el Server ID (clic derecho al nombre → Copiar ID, activa el modo desarrollador).
  4. Pégalo arriba y pulsa verificar.

⛏️ 2 · Conecta tu Minecraft

  1. Escribe la IP tal como entran tus jugadores (con :puerto si no es el normal).
  2. Si usas Bedrock dímelo y lo ajustamos.
  3. Pulsa probar: debe responder en verde.

🤖 3 · Asistente de conexión

Pregúntale cómo conectar algo o pídele que revise tu configuración.

¡Hola! Soy tu asistente. Puedo guiarte para activar el widget, conseguir IDs e IPs, o revisar si todo responde. ¿Por dónde empezamos?
